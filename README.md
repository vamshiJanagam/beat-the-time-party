Beat the Time
A fast, real-time word party game for 2–8 players. Create a room, invite friends, and take turns naming words before time runs out. Avoid repeats and forbidden starting letters to stay in the game.
Play
Play Beat the Time
Create a room and share its five-letter code with friends, or join an existing room with a code. On your turn, enter a valid word for the displayed category before the timer expires.
Features
- Real-time multiplayer rooms for up to eight players
- 24 categories with 1,592 curated word entries
- Room codes and open rooms for finding a game
- Character selection and a 3D tabletop arena
- Host-controlled pause and resume
- Separate music and sound controls
- Server-validated turns, categories, and answers
Built with
JavaScript, Three.js, Netlify Functions, and Netlify Blobs.
Assets
The game uses artwork and visuals created for the project. It does not include third-party character models or downloaded asset packs. See [ASSET_LICENSES.md](ASSET_LICENSES.md) for the asset note.
